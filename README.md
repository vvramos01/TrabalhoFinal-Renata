#  Portfólio Pessoal

Projeto desenvolvido como Trabalho Final da disciplina de Desenvolvimento Web.

## Sobre

Este projeto consiste em um portfólio pessoal desenvolvido utilizando HTML, CSS e JavaScript, com o objetivo de apresentar informações pessoais, habilidades, projetos e formas de contato de maneira organizada e responsiva.

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

##  Estrutura do projeto

O projeto é composto por três páginas principais:

- **index.html** – Página inicial com apresentação, informações pessoais e habilidades.
- **projetos.html** – Página contendo os principais projetos desenvolvidos.
- **contato.html** – Página com informações de contato e links para redes profissionais.

##  Funcionalidades

- Menu de navegação responsivo
- Animações utilizando CSS
- Efeito de digitação em JavaScript
- Animações ao rolar a página (Reveal on Scroll)
- Filtro de projetos por categoria
- Manipulação do DOM com JavaScript
- Layout responsivo para dispositivos móveis

##  Conceitos utilizados

- HTML semântico
- Flexbox
- Grid Layout
- Media Queries
- Variáveis CSS
- Animações CSS
- JavaScript
- Eventos
- Manipulação do DOM
- GitHub Pages
